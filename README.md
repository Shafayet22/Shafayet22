##  Featured Project: ESP32-WIDS

A **Wireless Intrusion Detection System** built from scratch on an ESP32 Dev Module. It's a hands-on project to understand WiFi attacks from the packet level.

- **Detects:** Deauth attacks, Beacon Floods, Probe Floods, and more
- **Method:** 802.11 Promiscuous Mode & Anomaly-based Detection
- **Features:** Real-time web dashboard, hardware alerts (LEDs/Buzzer)

🔗 **[Check out the ESP32-WIDS repository](https://github.com/Shafayet22/WIDS-ESP32)**
